# E-Commerce Sales Analysis

## 📊 Overview

Analysis of 2,000 e-commerce transactions to identify:
- Top-performing products
- Customer purchasing patterns
- Seasonal trends
- Strategic recommendations

## 🎯 Key Findings

✅ **Electronics dominates** with 83.5% of revenue  
✅ **Q4 sales spike** by 54.4% above average  
✅ **Return customers** have 1.1x higher lifetime value  
✅ **Top product** is Monitor with $402,905 revenue  

## 📁 Files

- `ecommerce_sales_analysis.py` - Main analysis script
- `outputs/` - Generated results:
  - 9-chart dashboard (PNG)
  - 6 CSV data files
  - Full transaction dataset

## 🚀 How to Run

```bash
pip install -r requirements.txt
python ecommerce_sales_analysis.py
```

All outputs will be generated in the `outputs/` folder.
